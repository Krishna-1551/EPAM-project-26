# XYZ Bank Customer Portal

## Overview

This project is a simple banking customer portal developed using HTML, CSS and JavaScript.

The application validates customer IDs and generates a random Diwali coupon for valid customers.

## Features

- Customer Registration
- Customer ID Validation
- Random Coupon Generation
- Interactive User Interface
- Input Validation

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Concepts Used

- Variables
- Arrays
- Functions
- Event Listeners
- DOM Manipulation
- Boolean
- if-else Statements
